Bagaimana cara menyelesaikan persamaan kuadrat dengan rumus abc?

Halo teman-teman dan tutor di EduConnect, saya sedang mempelajari bab Persamaan dan Fungsi Kuadrat di kelas 11 SMA. Saya masih sering ragu saat menentukan nilai diskriminan dan memasukkannya ke dalam rumus abc kuadratik.

Berikut adalah contoh persamaan kuadrat yang sedang saya selesaikan:

Contoh Soal:
2x² + 5x - 3 = 0

Pertanyaan yang ingin saya tanyakan:

  1. Bagaimana langkah sistematis menentukan nilai a, b, dan c serta menghitung nilai diskriminannya?
  2. Bagaimana cara memasukkan nilai tersebut ke dalam rumus abc sampai mendapatkan akar-akar x₁ dan x₂?
  3. Kapan sebaiknya kita memilih memakai rumus abc daripada metode pemfaktoran biasa?

Mohon bantuannya dengan penjelasan langkah demi langkah yang runtut agar mudah dipahami. Terima kasih banyak sebelumnya!

Terverifikasi

Halo Ahmad! Rumus abc (rumus kuadrat) adalah metode pasti yang selalu berhasil menyelesaikan semua jenis persamaan kuadrat bentuk ax² + bx + c = 0.

Rumus Kuadratik (abc):
x₁,₂ = [-b ± √(b² - 4ac)] / (2a)

Berikut adalah penyelesaian langkah demi langkah untuk persamaan 2x² + 5x - 3 = 0:

1 Identifikasi Nilai Koefisien a, b, dan c

Dari bentuk ax² + bx + c = 0, diperoleh:
• a = 2 (koefisien x²)
• b = 5 (koefisien x)
• c = -3 (konstanta)

2 Hitung Nilai Diskriminan (D = b² - 4ac)

D = 5² - 4(2)(-3)
D = 25 - (-24)
D = 25 + 24 = 49
Catatan: Karena D = 49 (D > 0 dan kuadrat sempurna), persamaan memiliki 2 akar riil yang berbeda dan rasional.

3 Substitusi Nilai ke Rumus abc

x = [-5 ± √49] / [2(2)]
x = [-5 ± 7] / 4

4 Hitung Akar x₁ dan x₂

• Untuk (+) : x₁ = (-5 + 7) / 4 = 2 / 4 = 1/2
• Untuk (-) : x₂ = (-5 - 7) / 4 = -12 / 4 = -3
Maka Himpunan Penyelesaiannya: HP = {-3, 1/2}

Tips Kapan Menggunakan Rumus abc:

Gunakan rumus abc jika koefisien angka sulit difaktorkan secara langsung atau jika akarnya berupa bilangan pecahan/bentuk akar (irasional). Jika mudah difaktorkan, metode pemfaktoran tetap lebih cepat.

Menambahkan informasi mengenai nilai Diskriminan (D) yang sangat sering keluar di soal ujian:

  • D > 0: Memiliki dua akar riil yang berlainan (seperti soal ini di mana D = 49).
  • D = 0: Memiliki dua akar kembar (akar riil yang sama).
  • D < 0: Tidak memiliki akar riil (akarnya imajiner).
